# IT Helpdesk Performance Dashboard

## Project Overview

This project demonstrates an interactive IT Helpdesk Performance Dashboard developed using Microsoft Power BI.

The dashboard analyzes 20 simulated IT support tickets from October 2026 to help stakeholders monitor ticket resolution, workload distribution, ticket priorities, and IT support performance.

## Project Objectives

- Monitor overall IT helpdesk performance.
- Track resolved, open, and pending tickets.
- Analyze tickets by priority and department.
- Identify common IT support issues.
- Monitor technician workload.
- Calculate the overall ticket resolution rate.

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---|
| Total Tickets | 20 |
| Resolved Tickets | 11 |
| Open Tickets | 4 |
| Resolution Rate | 55% |
| In Progress Tickets | 3 |
| Assigned Tickets | 2 |

## Dashboard Features

The dashboard includes:

- Ticket Status Analysis
- Ticket Priority Analysis
- Department-wise Ticket Distribution
- Issue Category Analysis
- Technician Workload Analysis
- Daily Ticket Trend
- Interactive Date, Priority, and Department Slicers

## Key Insights

- 55% of tickets were resolved during the reporting period.
- High, Medium, and Low priority categories each contain 6 tickets.
- Critical priority accounts for 2 tickets.
- Finance, HR, IT, and Sales each recorded 5 tickets.
- Each issue category contains 4 tickets.
- 4 tickets have no assigned technician recorded.
